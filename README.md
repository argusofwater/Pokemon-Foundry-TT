# Pokémon Tabletop Reunited — Commander Build

This private development fork analyzes, rebalances, and modernizes Pokémon Tabletop Reunited for a lighter player experience while preserving tactical battles, Pokémon identity, and the original creators' work.

## Current design work

- `docs/RULES-AUDIT.md` identifies the largest sources of player burden.
- `docs/PLAYER-LITE-RULES-DRAFT.md` contains the first proposed lighter rules spine.
- `CHANGELOG-PRIVATE.md` tracks private-build changes.

The current proposal explores two defenses instead of three evasions, a Main/Move/Reaction action economy, compressed damage tiers, simplified combat stages, four recharge categories, Wounds in place of default injury thresholds, and guided progression.

Baseline PTR behavior will remain available during prototyping so changes can be tested rather than welded permanently into the machinery.

# Original PTR System

The Pokémon Tabletop Reunited system for Foundry VTT is a continuation of the Pokémon Tabletop United system, with balance changes and new content created with Foundry VTT in mind.

Questions and feedback for the original project can be directed to the [PTR Discord Server](https://discord.gg/ptrfvtt).
