# Pokemon Foundry TT

Private-use development workspace for updating and streamlining a fan-created Pokemon tabletop ruleset for Foundry Virtual Tabletop.

## Project goals

- Preserve attribution to the original tabletop and Foundry system creators.
- Repair compatibility, automation, performance, and usability issues.
- Keep technical fixes separate from optional house-rule changes.
- Maintain a clear changelog so useful improvements can be offered back to the original creators.
- Do not bundle copyrighted commercial artwork or other proprietary media.

## Planned structure

- `docs/` - design notes, audits, migration plans, and attribution records
- `src/` - Foundry system source
- `packs/` - system compendium sources where legally appropriate
- `tools/` - importers, converters, validation, and migration utilities
- `tests/` - automated rules and data validation

## Development branches

- `core-fixes` - compatibility and bug fixes
- `foundry-v13` - Foundry VTT version support
- `rules-refactor` - streamlined optional mechanics
- `commander-house-rules` - table-specific rules and experiments

## Status

Repository initialized. Upstream source has not yet been imported.
